# Dataset

This project uses the **CGMacros** dataset, a public multimodal dataset that pairs
continuous glucose monitoring (CGM) traces with meal macronutrient logs, clinical
biomarkers, and food images.

- Source: [physionet.org/content/cgmacros/1.0.0](https://physionet.org/content/cgmacros/1.0.0/)

The raw dataset is not included in this repository — download it from the link above
and place it in a local `data/` folder before running the notebook or scripts.
